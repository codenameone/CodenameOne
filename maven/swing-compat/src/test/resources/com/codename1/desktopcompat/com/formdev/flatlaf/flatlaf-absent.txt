# The public classes of FlatLaf and FlatLaf Extras that this layer deliberately
# does not have. FlatLafApiShapeTest reads this file: a class of the real jars
# must be in the layer, or named here, or in a package named here with ".*".
# A line that names a class the layer does have fails the test, so the list
# cannot go stale.
#
# Whole packages. The UI delegates, icons and JSON reader are how FlatLaf
# paints Swing; here the widgets are Codename One components and the palette
# is a theme, so there is nothing for them to do. The extras components wrap
# Swing components to add FlatLaf-only properties.
