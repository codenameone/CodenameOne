# The nearest supported alternative to an API a device does not have.
#
# One row per line:   API prefix | what to use, by name | what to say
#
# - The prefix is the API as Java spells it: a package ending in a dot
#   (java.sql.), a class (java.lang.ProcessBuilder) or a member
#   (java.lang.Runtime.exec). The longest prefix that matches wins.
# - The second column lists the classes and members the advice names, comma
#   separated, a member as Class#member. ComplianceAlternativesTest fails
#   when one of them is not in codenameone-core, java-runtime or a
#   compatibility layer, so a row cannot point at something that is gone.
#   It is empty for a row that says there is no equivalent.
# - Adding a row is adding a line.
