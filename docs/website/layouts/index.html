Crypto in the app and server

Wallet APIs. Native kernels. Parallel verification.

Build Ethereum/EVM, Bitcoin and Solana wallets with shared Java APIs for key derivation, transaction signing and node access.

Use the CPU cores and GPU

Native kernels accelerate signatures and hashes. CryptoBatch distributes verification across CPU cores, with Metal, Vulkan or WebGPU batches on supported devices. GPU work uses public data, never private keys.

On an ARM64 API 36 Android emulator, native ECDSA verification measured 6.00× BouncyCastle. GPU gains vary with the device and batch size; portable Java paths cover other environments.
