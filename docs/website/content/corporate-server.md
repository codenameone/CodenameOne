# Corporate Server

Codename One Corporate runs the Codename One build and services stack inside an environment you control, for regulated and security-sensitive organizations that cannot build in a shared cloud.

- **Private cloud:** a dedicated, 100% private cloud hosted for you and isolated from other customers.
- **On premises:** an installation inside your own network, managed by your team.

Builds and runtime services stay inside that environment.

Pricing starts at **$25,000 USD annually** and depends on the deployment. Open the site chat to discuss your requirements. See the [pricing page](/pricing/#corporate) for the other plans.
