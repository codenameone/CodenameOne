model-viewer.js
===============

model-viewer.js is the distribution file dist/model-viewer.min.js of
<model-viewer> 3.5.0 by Google (https://github.com/google/model-viewer), from
the npm package @google/model-viewer, unmodified except that its last line, a
sourceMappingURL comment naming a source map that is not shipped, is removed.
fingerprint.py publishes it as src/main/resources/static/model-viewer.<hash>.js.
