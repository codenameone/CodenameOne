# A positional dimension and alt text split by a comma render identically:
# image::chart.png[Results, 2024] and image::ok.png[Diagram,640] both come out
# as alt="X" width="N". The render cannot tell which the author meant, so the
# ones already in the guide are recorded here and anything new has to be
# declared deliberately -- by adding a line, or by quoting the alt text if the
# number was really part of it.
#
# The alt text is part of the key so that an exemption covers ONE occurrence.
# Keyed on the image alone, a reuse of that image whose alt text was truncated
# to the same width would inherit the exemption.
#
