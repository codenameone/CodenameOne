package com.codename1.media.audio;

/// How much a [WaveShaperNode] oversamples while it applies its curve: the
/// Web Audio `"none"`, `"2x"` and `"4x"`. Oversampling keeps the harmonics a
/// hard curve creates from folding back as aliasing, at the cost of more work.
public enum OverSampleType {
    /// The curve is applied at the context's rate.
    NONE,
    /// The input is upsampled two times, shaped and filtered back down.
    TWO_X,
    /// The input is upsampled four times, shaped and filtered back down.
    FOUR_X
}
